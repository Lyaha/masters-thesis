# Вебплатформа моніторингу гендерного балансу в ІТ-освіті

MVP для магістерської кваліфікаційної роботи за спеціальністю 121 «Інженерія програмного забезпечення».

## Функціональність першої версії

- Перемикання між джерелами статистики: добровільні відповіді користувачів, відкриті українські та міжнародні дані.
- Дашборд із частками за гендером, гендерним індексом і розподілом за ЗВО/роком.
- Реєстрація, вхід та добровільне подання профілю для агрегованої статистики.
- Адміністративний API: створення й приховування категорій, керування API-джерелами, видалення старого набору даних перед імпортом нового.

## Запуск

1. Встановіть Docker і виконайте `docker compose up -d --wait`. Команда дочекається, поки PostgreSQL пройде перевірку готовності.
2. Скопіюйте `apps/api/.env.example` у `apps/api/.env`.
3. Виконайте `pnpm install`, потім `pnpm dev`.
4. Відкрийте `http://localhost:5173`.

Перевірка запущених контейнерів: `docker compose ps`. У стовпці статусу БД має бути `healthy`. Після завершення роботи зупиніть контейнер командою `docker compose down`; дані залишаться у томі `postgres_data`.

Демонстраційний адміністратор: `admin@example.com` / `admin123`. Перед реальним розгортанням обліковий запис і `JWT_SECRET` потрібно змінити.
