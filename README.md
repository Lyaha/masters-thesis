# Gender IT Observatory

Вебплатформа моніторингу та візуалізації показників ІТ-освіти для магістерської роботи за спеціальністю 121 «Інженерія програмного забезпечення».

Стек: React 18, TypeScript, Vite, Chart.js, Node.js/Express, PostgreSQL 16, Docker Compose. Це навчальний MVP, а не готовий до публічного розгортання сервіс.

## Можливості

- Публічний дашборд, фільтри, динаміка за роками та експорт CSV.
- Інтерактивний гендерний розподіл для джерел із відповідними даними.
- ЄДЕБО: вступ на ІТ-спеціальності; Eurostat: студенти ICT за країною, роком і статтю.
- Реєстрація, вхід і добровільний освітній профіль зі згодою на агрегування.
- Адмінпанель: категорії, реєстр API-джерел, створення категорії разом із джерелом, CSV-імпорт і транзакційна заміна набору.
- Українська/англійська мови; світла, темна й системна теми; адаптивний інтерфейс і toast-повідомлення.

ЄДЕБО **не містить гендерного розподілу** у використаному endpoint. Eurostat **не містить окремих ЗВО**. Демонстраційні дані відокремлені в «Тестові». Додавання URL в адмінпанелі не створює нового програмного адаптера. Деталі: [джерела та методика](docs/data-sources.md).

## Швидкий запуск у Windows

Потрібні Git, PowerShell та запущений Docker Desktop із Linux containers. Node.js і pnpm на хості для цього способу не потрібні.

```powershell
Set-Location 'E:\Windows\Desktop\masters-thesis'
./scripts/setup.ps1
docker compose up -d --build --wait
docker compose ps
```

Відкрийте [сайт](http://127.0.0.1:5173). Усі три сервіси мають статус `healthy`.

`setup.ps1` створює локальний `.env` з випадковими секретами й не перезаписує наявний файл. Облікові дані адміністратора: `ADMIN_EMAIL` та `ADMIN_PASSWORD` у цьому файлі. Не публікуйте його. Для **наявного старого тому** спочатку прочитайте [оновлення БД](docs/security.md).

Compose запускає три окремі контейнери однією командою: PostgreSQL, API та nginx із web-збіркою. Назовні доступний тільки web на loopback-порту 5173.

Зупинка без видалення даних:

```powershell
docker compose down
```

Не додавайте `-v`: це видалить том БД. Повний запуск, dev-режим, резервні копії й діагностика: [розгортання](docs/deployment.md).

## Перевірки для розробника

Node.js 22 і pnpm 11.19.0 відповідають конфігурації CI та Docker.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm format:check
```

Результати та межі перевірок: [тест-план](docs/testing.md). CI запускає тести й production build, але не повний Docker/browser-аудит.

## Структура

```text
apps/web/       React-клієнт, стилі, тести, nginx
apps/api/       Express API, адаптери, міграції, тести
database/       Початкова схема, демонстраційні дані
scripts/        Початкове налаштування секретів
docs/           Проєктна й експлуатаційна документація
.github/        Перевірки CI
```

Локальні `audit/`, `work/`, `outputs/`, `seed data/` та секрети виключені з Git. У чистому клоні немає тестового CSV на 15 000 рядків або локальних звітів аудиту.
