Документація описує реалізацію, звірену з кодом **28.09.2026**. Це документація програмного продукту, не готовий текст магістерської роботи та не висновок про відповідність університетським методичним вимогам.

## Використання в магістерській

| Частина роботи            | Матеріали проєкту                                             |
| ------------------------- | ------------------------------------------------------------- |
| Постановка задачі         | Специфікація, ролі, межі джерел                               |
| Проєктування              | Архітектурна схема, ER-модель, діаграма послідовності імпорту |
| Реалізація                | Контракти API, структура модулів, CSV і зовнішні адаптери     |
| Тестування й експлуатація | Тест-план, датовані результати, запуск і резервне копіювання  |
| Додатки                   | Інструкції; скриншоти слід зняти з фінальної версії           |

Діаграми записані як Mermaid у Markdown: потрібен переглядач із підтримкою Mermaid. Їх можна експортувати для пояснювальної записки. Приклади та діаграми не замінюють бібліографічних посилань на першоджерела у науковому тексті.

## Актуалізація

- Зміна маршруту/схеми запиту: оновити API та тести.
- Зміна SQL: оновити ER-модель і процедуру міграції.
- Зміна провайдера, років чи агрегації: оновити методику; не переносити старі кількості спостережень як незмінні.
- Зміна UI: оновити інструкції та ручні сценарії.
- Результати перевірок позначати датою й видом тесту; unit-тести не замінюють аудит.
- Не включати реальні JWT, паролі, `.env`, персональні профілі чи резервні копії.
