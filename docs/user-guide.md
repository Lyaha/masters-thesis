# Інструкція користувача

[Навігація](README.md)

## Перегляд статистики

1. Відкрийте сайт, локально — `http://127.0.0.1:5173`.
2. У полі «Джерело статистики» оберіть категорію; дочекайтеся завантаження.
3. Установіть рік, регіон/країну, ЗВО або спеціальність. Значення «Усі» прибирає відповідний фільтр. При зміні джерела фільтри скидаються.
4. Перегляньте метрики, динаміку й розподіл нижче фільтрів.

Для ЄДЕБО замість гендерних часток показано кількість вступників і попередження про відсутність гендерних даних. Для Eurostat немає фільтра ЗВО; для профілів немає регіону, а рік означає рік подання. Деталі: [методика](data-sources.md).

Коло у верхній частині спочатку показує частку чоловіків. Натисніть сектор або кнопку легенди, щоб зафіксувати іншу групу; доступні Enter/Space з клавіатури. Важливо: коло показує всю категорію, не поточні UI-фільтри.

Якщо результат порожній, поверніть фільтри до «Усі». Порожній результат не завжди означає нуль студентів: даних може не бути або вони не проходять правила повноти/приватності.

## Експорт

Натисніть «Експорт CSV» у блоці розподілу. Завантажується відфільтрований результат у UTF-8 з BOM; у ЄДЕБО експорт не обмежено топ-10 графіка. Формат експорту містить агреговані дані й підписи колонок; **це не формат зворотного імпорту**.

## Обліковий запис і профіль

1. Відкрийте «Вхід», перейдіть до реєстрації за потреби.
2. Укажіть email і пароль: щонайменше 8 символів, до 72 байтів UTF-8.
3. У «Мій профіль» оберіть ідентичність, ЗВО, спеціальність і рівень освіти.
4. Підтвердьте згоду та натисніть «Зберегти».

Без згоди профіль не записується. Повторне збереження оновлює власний запис, не створює ще одного учасника. Форма не завантажує раніше збережені значення автоматично. Поява в публічній статистиці залежить від порогу 5 учасників у групі; після збереження оновіть сторінку, щоб заново отримати агрегати.

Самостійне видалення профілю та відкликання згоди через UI поки не реалізовані. Для видалення звертайтеся до оператора інсталяції; автоматичного процесу/строку виконання система не задає.

«Вийти» видаляє локальну сесію; JWT сервером окремо не відкликається. На спільному ПК завершуйте сесію після роботи. Якщо API повернув 401, увійдіть повторно; після 429 зачекайте час із повідомлення/`Retry-After`.

## Тема, мова й повідомлення

У шапці доступні українська/англійська та світла/темна/системна тема. Типова тема — системна, типова мова — українська. Налаштування зберігаються у браузері, якщо localStorage доступний. Дані провайдера та серверні помилки можуть залишатися мовою джерела/українською.

Toast повідомляє про успіх або помилку. При збої зовнішнього джерела повторно оберіть категорію або оновіть сторінку; дані попередньої категорії не повинні підміняти нову.
