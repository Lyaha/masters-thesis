# Джерела даних і методика показників

[Навігація](README.md)

Цей документ описує **поточні параметри й перетворення у коді**, а не гарантує поточну повноту відповідей сторонніх API. Число країн, років і записів може змінюватися; у цій документаційній перевірці live-джерела повторно не опитувалися.

## Вбудовані категорії

| Slug                      | Категорія                 | Одиниця спостереження                                    | Гендерні дані                                |
| ------------------------- | ------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| `test-data`               | Тестові                   | ЗВО × регіон × спеціальність × рівень освіти × рік у CSV | Синтетичні або надані автором імпорту        |
| `ukraine-open-data`       | Відкриті джерела України  | Вступ за роком, ЗВО, регіоном і спеціальністю            | Немає у використаному endpoint               |
| `international-open-data` | Європейські відкриті дані | Країна × рік для ICT                                     | F, M, T із Eurostat                          |
| `site-users`              | Зареєстровані користувачі | ЗВО × спеціальність × рік подання                        | Добровільні відповіді, групи від 5 учасників |

## ЄДЕБО

Код: [it-open-data.ts](../apps/api/src/services/it-open-data.ts).

Дозволена базова адреса: `https://registry.edbo.gov.ua/api/opendata/university-entrant` (також варіант із завершальним `/`, що локально нормалізується). Запити додають `y`, `sp`, `qf=1`, `eb=40`, `exp=json`.

- Роки 2020–2024: внутрішні ID спеціальностей `1509, 1970, 1511, 1512, 1513, 2390, 1957`.
- Рік 2025: ID `2547, 2548, 2549, 2550, 2551, 2552`.
- Опис у застосунку позначає покриття як 121–126 та F2–F7. Для зміни відповідностей перевіряйте довідник провайдера; ID API не є самими кодами спеціальностей.
- На холодне завантаження — 41 запит, до 4 паралельно; тайм-аут окремого запиту 15 секунд, кеш 5 хвилин.
- `total` — сума шести полів: денна/заочна/вечірня форми, бюджет/контракт. Нечислові, непозитивні значення цих полів нормалізуються до 0; рядки з нульовою сумою пропускаються.
- 404 окремого запиту трактується як відсутність рядків; це не обов'язково збій усього завантаження.

Це показники вступу в обраному адаптером зрізі, не весь контингент студентів. Не можна обчислювати з них частки чоловіків/жінок. Роки жорстко задано до 2025: новий календарний рік не додається автоматично.

## Eurostat

Код: [eurostat-it-open-data.ts](../apps/api/src/services/eurostat-it-open-data.ts).

Endpoint: `https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/educ_uoe_enrt03`.

| Параметр адаптера | Значення                                           |
| ----------------- | -------------------------------------------------- |
| `lang`            | `en`                                               |
| `geoLevel`        | `country`                                          |
| `sinceTimePeriod` | `2013`                                             |
| `isced11`         | `ED5-8`                                            |
| `iscedf13`        | `F06` — Information and communication technologies |
| `unit`            | `NR`                                               |
| `freq`            | `A`                                                |

Адаптер читає доступні країни/роки з dimension metadata, не має жорсткого списку лише з Польщі, Франції, Німеччини чи Великої Британії. Наявність кожної країни за кожен рік не гарантується. Тайм-аут — 30 секунд, кеш — 12 годин.

До відповіді входять лише повні невід'ємні цілі `F`, `M`, `T`, де `T >= F + M`. Відсутні значення не підміняються нулем. Поле `nonbinary` спільного UI-контракту дорівнює `T - F - M`: це арифметичний залишок, **не встановлена кількість небінарних студентів**. Окремої інтерпретації всіх quality/status-позначок джерела адаптер не виконує.

Внутрішні `region` і `institution` обидва містять назву країни для сумісності типів. UI приховує ЗВО й підписує регіон як країну. F06 та українські спеціальності не є автоматично доведеною взаємно однозначною класифікацією.

## Добровільні профілі

Рік — рік останнього збереження профілю (`consent_given_at`), не рік вступу. Групування: ЗВО, спеціальність, рік; рівні освіти об'єднуються. Регіон не збирається.

Публікуються лише групи з кількістю >= 5. «Інші» об'єднує `nonbinary` та `prefer_not_to_say`, тому не є лише небінарною ідентичністю. Це самозвітна нерепрезентативна вибірка. Поріг групи зменшує деталізацію, але не доводить анонімності.

## Формули та трактування

Для гендерного дашборду `W`, `M`, `N` — суми лічильників вибраних рядків:

```text
T = W + M + N
Частка жінок = round(100 × W / T)
Частка чоловіків = round(100 × M / T)
Індекс = W / M, два знаки після коми
```

За T=0 частки показані як 0; за M=0 індекс — «—». Через округлення частки можуть не складатися точно у 100%. Індекс описує співвідношення лічильників, не причинність чи рівень дискримінації.

- Сума за кілька років — сума спостережень, не число унікальних людей: одна людина може бути врахована в різні роки.
- У Eurostat набір країн із повними даними може відрізнятися між роками; зміна суми не обов'язково означає реальну зміну за незмінною вибіркою.
- UI-фільтри впливають на нижні метрики, графіки й експорт. Верхнє коло наразі використовує всі завантажені рядки категорії.
- У ЄДЕБО нижній розподіл показує топ-10 ЗВО за сумою, а CSV-експорт містить усі відфільтровані рядки.
- Назви країн/ЗВО/спеціальностей не нормалізуються до спільного довідника. Різний правопис у CSV і профілях створює різні групи.
- Інтерфейс двомовний, але введені користувачем назви й дані провайдерів не перекладаються автоматично.

## Підключення нового провайдера

Потрібні аналіз контракту, окремий адаптер, розширення allowlist, вибір маршрутом, відповідний `kind`/UI та тести пропусків і помилок. Запис у реєстрі API-джерел цього не робить. HTTP-редиректи заборонені; кеш розділено за URL, паралельні завантаження об'єднуються.
