# Інструкція адміністратора

[Навігація](README.md) · [API](api.md) · [Розгортання](deployment.md)

## Доступ і категорії

Увійдіть із локальними `ADMIN_EMAIL`/`ADMIN_PASSWORD`, створеними під час налаштування. Реєстрація через сайт не надає ролі адміністратора. Зміна `ADMIN_PASSWORD` у `.env` не скидає пароль уже створеного звичайного адміністратора.

У «Адмінпанель → Категорії» введіть назву й опис та натисніть «Створити». Кнопки «Приховати»/«Показати» керують публічною видимістю. Приховування не видаляє набори. Видалення категорій через API/UI немає; перейменування доступне через API, але не через поточну форму.

## Джерела

У «API-джерела» оберіть наявну категорію або «+ Нова категорія», заповніть назву/опис нової категорії, назву джерела, тип і адресу за потреби. Категорія та джерело створюються транзакційно. Якщо slug категорії вже існує, використовується вона.

Підтримуються тільки дозволені адреси ЄДЕБО та Eurostat; для CSV/manual адресу можна залишити порожньою. Створення довільного запису типу `api` не налаштовує отримання довільного JSON: потрібен адаптер у коді.

Для вбудованих live-джерел важливі точні назви:

- `ЄДЕБО: вступ на ІТ-спеціальності` у `ukraine-open-data`.
- `Eurostat: ІТ-студенти за країною та статтю` у `international-open-data`.

Не створюйте дублікати й не перейменовуйте їх без зміни маршрутизації: вибір першого збігу не має визначеного сортування. Вимкнення єдиного придатного джерела робить live-категорію недоступною (503). Вимкнення CSV/manual-запису не приховує пов'язані імпортовані набори — для цього використовуйте видимість категорії.

«Видалити» прибирає запис джерела; FK наявних наборів може заборонити операцію з 409. Вбудоване джерело після видалення може бути відновлене стартовим `ensureBuiltInSources()`: для тимчасового відключення використовуйте «Вимкнути».

## Формат імпортного CSV

UTF-8 (BOM дозволений), роздільник — **кома**, перший рядок — назви колонок. Один запис займає один фізичний рядок; багаторядкові значення у лапках і роздільник `;` не підтримуються. Лапки навколо комірки з комою підтримуються, внутрішня лапка подвоюється.

```csv
institution,region,specialty,educationLevel,year,womenCount,menCount,nonbinaryCount
Тестовий університет,Київ,121 Інженерія програмного забезпечення,бакалавр,2025,120,210,3
```

| Колонки                                                | Умова                                                             |
| ------------------------------------------------------ | ----------------------------------------------------------------- |
| `institution`, `region`, `specialty`, `educationLevel` | Непорожній текст від 2 символів після обрізання крайових пробілів |
| `year`                                                 | Цілі цифри, 2000–2100                                             |
| `womenCount`, `menCount`, `nonbinaryCount`             | Цілі цифри, 0–2 147 483 647; нуль записувати як `0`               |

Усі вісім колонок обов'язкові; використовуйте кожну рівно один раз. Ключ рядка — ЗВО, регіон, спеціальність, рівень освіти, рік; дублікати в одному файлі заборонені. Різний правопис не нормалізується автоматично.

Ліміти: 20 000 записів, 10 МіБ CSV і окремо 10 МіБ JSON запиту. JSON більший за CSV; файл, близький до межі, може пройти preview, але отримати 413 при відправленні. Розділіть його на менші непересічні набори або скоротіть надмірні текстові поля. Експорт із дашборду без перетворення сюди не підходить.

## Імпорт і заміна

1. Оберіть «Імпорт CSV». Початкова форма порожня.
2. Оберіть «Тестові» або власну категорію. Профілі та live-категорії недоступні для CSV.
3. Укажіть змістовну назву й період; типові значення форми не виводяться автоматично з файлу.
4. Для нового набору залиште «Не замінювати». Для оновлення явно виберіть старий набір; список не обмежений лише поточною категорією, тому звіряйте назву.
5. Оберіть CSV-файл або вставте текст. Перевірте кількість і перші 5 рядків preview.
6. Натисніть «Імпортувати» один раз. Під час читання/збереження показано стан; форма заблокована. Не закривайте сторінку.
7. Після успіху файл, CSV і preview очищаються; повідомлення містить число записів. Для наступного імпорту потрібно знову вибрати файл або вставити текст.

При помилці ввід залишається. Якщо підтвердження втрачено, спочатку перевірте `GET /admin/datasets` або перелік у полі заміни. Сервер не має idempotency key: повтор без заміни створить новий набір, навіть із тими самими спостереженнями.

Заміна є атомарною, але не архівацією: старі записи фізично видаляються після успішного COMMIT. Зробіть backup перед цінними змінами. Окремий DELETE набору доступний через API; кнопки видалення набору в поточному UI немає.

Після імпорту перейдіть на дашборд і заново виберіть категорію/оновіть сторінку. Якщо імпорт містить бакалаврів і магістрів з однаковими іншими вимірами, API підсумує їх: наприклад, 15 000 записів можуть дати 7 500 агрегованих рядків.

Локальний `seed data/it-education-test-15000.csv`, якщо його було створено в цій інсталяції, містить синтетичні записи, не реальні дані ЗВО. Папка ігнорується Git; у чистому клоні файл відсутній.
