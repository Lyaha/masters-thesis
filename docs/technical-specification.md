# Технічне завдання MVP

## Призначення
Платформа збирає, зберігає та візуалізує агреговані гендерні показники ІТ-освіти. Перший реліз працює зі штучним набором даних; наступний етап додає адаптери до відкритих API.

## Ролі
- **Гість:** переглядає лише видимі категорії та публічні агреговані показники.
- **Користувач:** реєструється і, за явною згодою, надсилає дані профілю для статистики.
- **Адміністратор:** створює/приховує категорії, створює/оновлює/видаляє API-джерела, видаляє застарілий набір та імпортує новий.

## Базові категорії
1. Зареєстровані користувачі.
2. Відкриті джерела України.
3. Міжнародні відкриті джерела.

## Правила даних
У публічному інтерфейсі не зберігаються й не показуються персональні записи. Дані користувача зберігаються лише після підтвердження згоди та використовуються агреговано. Оновлення зовнішнього набору виконується як: перевірка нового набору → видалення/архівація старого → імпорт нового → активація.

## Імпорт
`POST /admin/datasets/import` приймає метадані набору та масив нормалізованих записів. Параметр `replaceDatasetId` дозволяє атомарно замінити старий набір: старий буде видалено тільки всередині успішної транзакції імпорту.

## Уточнення після аудиту безпеки

Імпорт обмежений 2 МіБ JSON та 5000 записами; унікальне спостереження включає регіон. Приховані категорії не видають публічних даних. Зовнішні адаптери застосовують ті самі API-фільтри, що й імпортовані набори; незавершені запити іншого джерела не змінюють поточний дашборд.

Добровільні профілі агрегуються за закладом, спеціальністю й роком подання. Групи менше 5 учасників не публікуються. Рік подання не є роком вступу/навчання; регіон не збирається. У Eurostat відсутнє спостереження не прирівнюється до нуля: порівняння використовує тільки повні узгоджені значення. Подробиці конфігурації й контрактів: [security.md](security.md).
